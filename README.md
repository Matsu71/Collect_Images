# Collect Images — 現生生物の実写画像集

ChronoEarth の現生生物を起点に、他のサービスでも再利用できる生物写真を収集します。絶滅生物の復元画・AI生成画像はこのコレクションの対象外です。

## 収集方針

- 動物・植物など現在生きている生物の実写。全体像・特徴が読み取りやすい写真を優先します。
- 商用利用・再配布・必要な加工を許すことが明示された CC0、CC BY、CC BY-SA を対象とし、非商用限定（NC）、改変禁止（ND）、権利不明は除外します。
- ライセンスは画像ごとに適用されます。このリポジトリ全体を一律の写真ライセンスで再許諾しません。
- 写真本体と作者・出典ページ・元画像URL・ライセンスURL・取得日時・加工内容・ハッシュを一緒に保存します。
- 自動取得・権利メタデータ照合と、実際の写真を見た品質／種同定の確認は別の状態として記録します。未確認画像を目視合格と表示しません。
- ChronoEarth の公開サービスや元リポジトリは変更しません。既存の約500件を優先し、将来1,000〜2,000件へ拡張できる独立した分類・台帳にします。

## 商用利用時

各画像のメタデータにあるクレジット、出典、ライセンスリンクを保持してください。CC BY-SA の写真を改変した場合は、改変写真にも該当ライセンス条件が必要です。人物・商標・撮影場所等の別の権利まで一律に保証するものではありません。

公式条件: https://creativecommons.org/licenses/by/4.0/ / https://creativecommons.org/licenses/by-sa/4.0/ / https://creativecommons.org/publicdomain/zero/1.0/

## 保存内容

- `data/targets.json`: 元サービスの現生生物との対応表
- `images/`: 写真ファイル（外部URLだけではなく実体）
- `metadata/`: 写真ごとの権利情報と出典
- `catalog/`: 再利用用の機械可読台帳・クレジット
- `reports/`: 取得件数、未取得理由、レビュー状態
- `gallery/`: 写真を目視確認するための一覧
- `scripts/`: 再開可能な収集・検証処理

収集実績は `reports/status.json` に記録します。セットアップ用ファイルの作成だけを、画像収集完了とは数えません。
