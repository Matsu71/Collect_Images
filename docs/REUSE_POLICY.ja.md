# 現生生物写真の再利用・品質基準

## この画像集の目的

現生生物の姿を知るための実写写真を、ChronoEarth だけに依存しない素材集として蓄積する。最初に ChronoEarth の現生生物を優先し、その後は動物・植物の追加候補へ広げる。種・亜種・属等を同一の「種数」として誤集計しない。

ChronoEarth の元リポジトリや公開画面へ画像を自動反映するものではない。画像と権利情報を `Collect_Images` に保存し、採用は利用先で選択する。

## 権利条件

受け入れるのは、画像自体に適用される CC0、CC BY、CC BY-SA の明示が確認できたもの。写真掲載サイトの利用条件や観察データのライセンスを、写真のライセンスと混同しない。NC（非商用）、ND（改変禁止）、All rights reserved、権利不明の写真は取得対象から除外する。パブリックドメインという単語だけの記載は、自動収集では採用しない。

- CC0: 著作権上の制約を極力取り除く宣言。ただし撮影対象等の別の権利まで保証しない。出典は追跡のため保持する。
- CC BY: 作者・作品名（提供されている場合）・出典・ライセンスへのリンク・加工内容を表示する。
- CC BY-SA: 上記に加えて、写真を改変して配布する場合、その改変写真に適切な同一ライセンス条件を適用する。写真の出典とライセンスを外した一括再許諾はしない。

画像ごとの `metadata/` と `catalog/credits.csv` を画像本体と一緒に移す。画像だけをコピーしてクレジット情報を失わない。作者のウェブサイトなど指定の帰属先がある場合は元メタデータも参照する。クレジットは免責文だけを別ページに置くのではなく、画像に対応することが分かる表示にする。

公式条件:
- https://creativecommons.org/publicdomain/zero/1.0/
- https://creativecommons.org/licenses/by/4.0/
- https://creativecommons.org/licenses/by-sa/4.0/
- https://help.inaturalist.org/en/support/solutions/articles/151000169918-can-i-use-the-photos-and-sounds-that-are-posted-on-inaturalist-
- https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia

取得時点のライセンスメタデータ、取得日時、出典URL、ファイルハッシュを保存する。これは権利元の申告を確認した記録であり、著作権の帰属や人物・商標・撮影場所等を含む一切の権利を法的に保証するものではない。

## 写真の選定とレビュー

自動処理は、学名対応、ライセンス、解像度、ファイルの正常性、明示的なイラスト・化石等の語句を確認する。観察の研究グレードや分類群の代表画像は選定材料だが、全身が写っていること・種同定が正しいことの保証にはしない。

目視確認では次を区別する。

1. **主画像候補**: 実写で、主体が十分大きく、動物では頭部・胴体・主要な付属肢／尾等、植物では樹形・草姿等の全体像が分かる。背景への埋没や大きな切れ・遮蔽がない。
2. **補足画像候補**: 花、葉、果実、顔、羽、殻等の特徴は明瞭だが、全体像を説明する主画像には不十分。主画像の代わりに黙って採用しない。
3. **差し替え候補**: 強いぼけ、主体が小さい、全体像が大きく欠ける、死体・標本、イラスト、透かし、誤同定の懸念など。

小さな一覧での目視は構図のスクリーニングであり、近縁種の専門的同定や原寸での精密画質確認とは別。未確認は `pending` のまま残す。写真が一枚保存できたことだけで `approved` を付けない。

## 画像形式

- `*.jpg`: 保存・再利用用の高品質JPEG。長辺は最大2,048 px。元ファイルそのものではなく、EXIF方向の適用・縮小・再圧縮をした版。
- `*.webp`: Web配信用。長辺は最大1,400 px。容量と画質を調整する。
- `*-thumb.webp`: 一覧用の小さなサムネイル。同じ写真の別形式なので、収集写真数に重複計上しない。

縦横比を保ち、被写体を切り取るトリミングや生成AIによる補完はしない。元画像のURL、取得したバイト列のハッシュ、加工内容、出力サイズを記録する。第三者の写真のライセンスは、これらの縮小版にも保持する。

## APIへの配慮・再開

iNaturalist API は同一実行元から概ね1秒以上の間隔でアクセスし、429等では待機して再試行する。既に保存できた生物を再取得せず、処理途中でも写真・メタデータ・集計を小分けにコミットする。大量画像を同時にブラウザで読み込まない。

API基準: https://www.inaturalist.org/pages/api+recommended+practices
画像メタデータAPI: https://www.mediawiki.org/wiki/API:Imageinfo

GitHub Actions はこの収集を実行するための単発実行と手動再実行用。時刻ベースの定期実行は設定していない。今後の拡張候補数は `MAX_TARGETS` で指定できるが、採用や目視合格数とは別。
